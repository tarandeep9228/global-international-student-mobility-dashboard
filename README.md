Global International Student Mobility Analysis (2015–2024)
Overview
This Power BI dashboard analyzes international student mobility trends from 2015 to 2024.

Key Metrics
Total Students: 31 Million
Destination Countries: 60
Origin Countries: 10
Years Covered: 2015–2024
Key Insights
International student mobility increased from 2.5M in 2015 to 3.6M in 2024.
USA emerged as the leading destination country.
India and China are the largest source countries.
Male and Female student participation remained relatively balanced.
Dashboard Features
Student Trend Analysis
Destination Country Analysis
Origin Country Analysis
Geographic Distribution Map
Gender Distribution
Origin-Destination Matrix
